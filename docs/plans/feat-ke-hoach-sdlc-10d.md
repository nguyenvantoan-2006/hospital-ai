## 🏛️ I. NGUYÊN TẮC PHÂN CHIA FRONTEND & BACKEND (FULL-STACK 2 DEV)

Cả 2 thành viên đều đảm nhiệm cả **Frontend (FE)** và **Backend (BE)** theo từng phân hệ nghiệp vụ, tuân thủ **Zero-Conflict Protocol**:

- **Nguyễn Văn Toàn (Lead):**
  - **Backend:** API Đặt lịch online, kiểm soát capacity khung giờ, gửi OTP Gmail kèm rate limit (`routers/lich_khams.py`, `email_service.py`), API Queue display Kiosk Smart TV, Tích hợp Google Gemini API & RAG cơ sở dữ liệu 37 khoa (`routers/ai.py`), Viết test scripts tự động (`test_appointment_capacity_sync.py`), Security Audit.
  - **Frontend:** Cổng Đặt lịch khám online (`templates/dat_lich_online.html`), Màn hình Kiosk Smart TV phát loa tiếng Việt (`templates/man_hinh_phong_kham.html`), Cổng tra cứu bảo mật theo SĐT (`templates/index.html`), Form Bác sĩ khám bệnh & autocomplete thuốc, in ấn A5 (`templates/lap_phieu_kham.html`), Floating Widget AI Chatbot đa phương thức Voice STT & Vision (`static/js/chatbot.js`).
- **Trần Thị Loan:**
  - **Backend:** Xác thực JWT & phân quyền RBAC 4 vai trò (`routers/auth.py`), API Quản lý hồ sơ bệnh nhân (`routers/benh_nhans.py`), API Phiếu khám lưu chẩn đoán ICD & đơn thuốc điện tử (`routers/phieu_khams.py`), API Kế toán viện phí & Database Transaction trừ kho dược ACID (`routers/hoa_dons.py`, `routers/ke_toan.py`), Cơ chế Data Masking `mask_pii()` và Bảng kiểm toán `AILog` (`models.py`).
  - **Frontend:** Giao diện Đăng nhập & session guard (`templates/login.html`), Giao diện Lễ tân tiếp đón & cấp STT (`templates/lich_kham.html`), Màn hình Thu ngân viện phí (`templates/ke_toan.html`), Quầy thuốc quản lý xuất kho & cảnh báo tồn kho (`templates/quay_thuoc.html`).
